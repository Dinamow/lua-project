# SOP: Exit & Re-Entry Visa Process (KSA) (Mock)

**Applies to:** KSA-based non-Saudi employees traveling abroad and returning.

1. Employee submits an exit/re-entry visa request through the HR agent at least 5 working days before travel, specifying single or multiple re-entry and expected return date.
2. HR verifies the employee's Iqama is valid for at least 90 days beyond the planned return date — if it's expiring sooner, HR flags an Iqama renewal first (see Iqama expiry alerts).
3. HR processes the visa through the Muqeem/Absher employer portal and shares the confirmation with the employee.
4. Employee must return by the visa's validity date (typically up to 90 days for single re-entry, up to 180 days aggregate for multiple re-entry within a year) or risk work-permit cancellation.

**Fees:** Multiple re-entry visas cost more than single re-entry; the company covers standard fees, employee covers optional expedited processing.
